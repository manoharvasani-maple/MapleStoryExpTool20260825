# OCR model source

The bundled `resources/models/PP-OCRv6_tiny_rec_onnx` model comes from
PaddlePaddle's PP-OCRv6 tiny recognition model:

https://huggingface.co/PaddlePaddle/PP-OCRv6_tiny_rec_onnx
