# MapleStoryExpTool 1.1.0

新楓之谷：經典版經驗值、楓幣與藥水成本追蹤工具。

## 新增功能

- 背包開啟時自動讀取目前楓幣；背包可放在遊戲視窗內任意位置。
- 讀取右下快捷欄 `Del` 的 HP 藥水與 `Ins` 的 MP 藥水數量。
- 顯示目前楓幣，並累計本次追蹤期間的楓幣收入與 HP／MP 藥水消耗。
- 可在設定中輸入兩種藥水的單價。
- 顯示藥水成本與扣除藥水後的淨收益。

淨收益公式：

```text
楓幣正向增量總和 - (HP 消耗量 × HP 單價) - (MP 消耗量 × MP 單價)
```

補充藥水造成的快捷欄數量增加不會算成消耗。新的畫面讀數必須連續
出現兩次才會採用，並會拒絕單次異常的大量藥水下降。

## 執行

需要 Windows 與 Python 3.10 以上版本：

```powershell
python -m pip install -r requirements.txt
python main.py
```

程式會尋找標題為 `新楓之谷：經典版` 的遊戲視窗。

## 使用限制

- 背包關閉時無法讀取楓幣；再次開啟後會比較最後一次確認的數值。
- 如果背包關閉期間同時有收入及支出，只能取得重新開啟時的合併差額。
- HP 藥水需放在 `Del`，MP 藥水需放在 `Ins`，並保持預設右下快捷欄外觀。
