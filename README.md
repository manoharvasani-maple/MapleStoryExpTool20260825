# MapleStoryExpTool 1.1.9

新楓之谷：經典版經驗值、楓幣與藥水成本追蹤工具。

## 新增功能

- 背包開啟時自動讀取目前楓幣；背包可放在遊戲視窗內任意位置。
- 讀取右下快捷欄 `Del` 的 HP 藥水與 `Ins` 的 MP 藥水數量。
- 顯示目前楓幣，並計算本次追蹤期間的楓幣淨變化與 HP／MP 藥水淨消耗。
- 可在設定中輸入兩種藥水的單價。
- 顯示藥水成本與扣除藥水後的淨收益。
- 「時間停止」可暫停持續時間與經驗速率統計；再次按下「時間繼續」即可接續，暫停期間不會列入計算。

淨收益公式：

```text
(目前楓幣 - 重置時楓幣) - (HP 淨消耗 × HP 單價) - (MP 淨消耗 × MP 單價)
```

1.1.7 改用「起始／結束快照」。按下重置後會自動偵測起始 HP／MP
藥水數量；練功途中所有藥水 OCR 變化都不會修改消耗。練功結束後可按
「偵測結算」重新讀取目前數量，或按「手動結算」輸入結束數量。藥水
淨消耗等於起始數量減去結束數量，因此練功途中取得的藥水會自然抵銷
消耗，結果也可為負數。

1.1.5 擴大並校正 `Del`／`Ins` 的數字裁切範圍，同時使用多種放大方式
交叉辨識像素字體，避免把 `773` 誤讀成 `763`、或把 `1510` 誤讀成
`1500`，造成一次跳 10 瓶或錯誤顯示 `-8`。

1.1.6 不再鎖死快捷欄數字位數或在平票時一律保留舊值。白水會從多個
文字裁切範圍交叉辨識，再交由連續畫面確認；因此可記錄一瓶消耗以及
`1000 → 999` 等位數變化。按下重置時也會清除 OCR 快取，避免錯誤舊值
讓後續讀數卡住。診斷日誌會記錄接受及拒絕的 HP／MP 候選值。

## 藥水結算流程

1. 將 HP 藥水放在 `Del`、MP 藥水放在 `Ins`，然後按一次重置。
2. 等畫面顯示兩種藥水的起始數量後開始練功。
3. 練功結束時按「偵測結算」。若辨識失敗，改按「手動結算」。
4. 程式以兩次數量差計算藥水消耗、藥水成本與扣除藥水後淨收益。

如果自動取得的起始數量不正確，請先按「修正起始」手動輸入正確的
HP／MP 起始數量，再開始練功或進行結算。這可處理藥水圖案或快捷欄
邊緣被 OCR 誤認成額外數字的情況，例如把 `702` 看成 `7022`。

楓幣使用按下重置後的第一筆確認值作為基準。畫面辨識暫時變小再恢復時，
不會把恢復成正確數字重複累加為收入。楓幣淨變化可為負數，代表目前
持有楓幣少於重置時。

## 診斷日誌

程式會把啟動資訊、遊戲視窗連線狀態、畫面擷取例外、介面模板分數、
OCR 例外與未處理例外寫入：

```text
%APPDATA%\ExpTracker\error.log
```

設定頁的「開啟錯誤紀錄資料夾」可直接開啟該位置。日誌不會儲存遊戲
截圖，只記錄診斷文字。單一檔案上限約 1 MB，並保留最多 3 份舊檔案，
避免長時間使用造成日誌無限增長。

## 執行

需要 Windows 與 Python 3.10 以上版本：

```powershell
python -m pip install -r requirements.txt
python main.py
```

程式會尋找標題為 `新楓之谷：經典版` 的遊戲視窗。

## 使用限制

- 背包關閉時無法讀取楓幣；再次開啟後會比較最後一次確認的數值。
- 如果背包關閉期間同時有收入及支出，只能取得重新開啟時的合併差額。
- HP 藥水需放在 `Del`，MP 藥水需放在 `Ins`，並保持預設右下快捷欄外觀。
